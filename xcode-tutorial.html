用 Xcode 把「简易笔记」iOS 版装到 iPhone

备用方案Sideloadly 的 -22406 在新系统上握手不稳，改用苹果官方的 Xcode 签名通道——原生、最稳，免费 Apple ID 即可。

开始前先说清：Xcode 体积约 15 GB，第一次下载很慢，建议挂机。装好后签名安装只是点几下。整个过程不需要越狱，免费账号签名有效期 7 天（到期重连 Xcode 点一次 Run 即可续）。

1安装 Xcode（约 15GB）

我已经在 App Store 里帮你打开了 Xcode 页面。如果没跳出来，自己打开 App Store 搜 Xcode。

耐心等下载完成（进度在 Launchpad 或 App Store「已购」里看）。下完会自动「安装」，可能还要等几分钟解压。

2首次启动：装组件 + 同意许可

第一次打开 Xcode 会弹两个框，都点同意 / 安装：

  • 弹「Install additional required components?」→ 点 Install，输入开机密码。
  • 弹许可协议 → 点 Agree。
  • 首次还会让你选「Platforms」，确保 iOS 勾上（默认就有）。
这一步会再装几个 GB 的 iOS 模拟器/设备支持组件，同样等它跑完。

3打开工程

在你 Mac 上打开终端，运行下面任意一条（工程已经在仓库里了）：

open /home/user/WorkBuddy/2026-10-17-21-34-18/easynote/mobile/ios/App/App.xcodeproj

或者 Finder 里进到 easynote/mobile/ios/App/，双击 App.xcodeproj。Xcode 打开后左侧导航应看到 App 工程。

工程已为你配好：自动签名、Bundle ID com.feibixunchang.easynote、版本 1.0.0、共享 scheme 已建。不需要你改任何构建设置。

4登录你的 Apple ID

菜单栏：Xcode → Settings…（或 Preferences） → 切到 Accounts 标签页 → 左下角 + → 选 Apple ID → 登录 your-apple-id@example.com（用你平时那个密码，不是应用专用密码）。

找不到 Settings？看这里：它是屏幕最上方那一行菜单栏里、最左边的「Xcode」菜单（带 Xcode 图标的那个，不是 File/Edit/View）。点开后往下拉，在「Quit Xcode」上方就是 Settings…。进去后顶部一排标签里点 Accounts。

5选签名团队

左侧选中 TARGETS → App → 右侧切到 Signing & Capabilities：

6iPhone 上开启「开发者模式」（iOS 16+ 必须）

这一步很多人漏掉，漏了会卡在「无法运行」。在 iPhone 上：

设置 → 隐私与安全性 → 开发者模式 → 打开 → 按提示重启 iPhone。

如果没看到「开发者模式」选项：先把 iPhone 连上 Mac 并让 Xcode 识别一次（下一步），选项通常就会出现；或者先在 Xcode 里跑一次，它也会提示你开。

7连手机 + 运行（Cmd+R）

iPhone 已经信任过这台 Mac，直接连上。Xcode 顶部工具栏「设备选择器」（▶ 旁边）选你的 iPhone。然后按 ⌘ R（或点左上角 ▶ 运行）。

回 iPhone 主屏，点 简易笔记 图标即可使用。桌面端/手机端用同一个同步账号，笔记会自动打通。

✅ 安装完成

↻7 天后续签（免费账号必做）

免费签名 7 天后 App 会打不开（图标还在但点开闪退）。续签只需：

  • iPhone 连上 Mac，Xcode 打开本工程 → ⌘ R 重新跑一次。
  • 或装了 Xcode 后顺手开「Settings → Accounts」里保持登录，连上重跑即可。
想彻底免续签只能入 付费 $99/年 的 Apple Developer Program，普通用户 7 天续一次完全够用。

!常见报错速查

  • 「Failed to register bundle identifier」：Bundle ID 被占，改成你独有的（如 com.example.easynote），回到第 5 步重选 Team。
  • 「Could not launch — not trusted」：没做第 8 步，去设置信任开发者。
  • 「iPhone is busy / 准备设备」：第一次连等几十秒，或重启 Xcode / 重插线。
  • 「Developer Mode not enabled」：做第 6 步，iPhone 开开发者模式并重启。
  • 「No signing certificate」：第 4 步 Apple ID 没登录成功，或网络被墙导致苹果服务器连不上（挂代理再试）。
  • 真机跑起来白屏：前端资源没进包。本工程已构建好 mobile/www，正常不会出现；若你改过代码，先在 mobile 目录跑 npm run build 再开 Xcode。
