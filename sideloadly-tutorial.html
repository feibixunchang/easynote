📱 简易笔记 · iOS 安装教程

用 Sideloadly 把未签名的 IPA 装到 iPhone / iPad（免费 Apple ID，无需越狱）

Sideloadly v0.71.0 · macOS 10.12+ / Windows 7+ · iOS 7–27+
⚠️ 先看这条： 用免费 Apple ID 签名装的 App 每 7 天会过期（系统限制，不是 bug）。 过期后 App 图标变灰、打不开，只要把 iPhone 重新连上电脑、打开 Sideloadly 点一次 Start 就能续命。 开启 Sideloadly 的「Anisette / Auto-Refresh」后还能自动续签，几乎无感。本教程第 9 步会讲。

1 下载并安装 Sideloadly

去官网下载对应系统的安装包，装到电脑上（Mac 或 Windows 都行）。

  • 官网：https://sideloadly.io
  • macOS：下载 SideloadlySetup.dmg → 打开把 Sideloadly 拖进「应用程序」
  • Windows：下载 SideloadlySetup64.exe 双击安装
  • Windows 用户额外需要：Apple Devices（或 iTunes） 提供驱动，否则手机连不上。去微软商店搜 “Apple Devices” 安装即可

2 连接 iPhone 并「信任此电脑」

用数据线把 iPhone 连到电脑。手机上会弹一个对话框，一定要点「信任」。

信任此电脑？
「Sideloadly」想要信任此电脑，并允许其访问你的设备上的数据。
不信任
信任

点「信任」后，再输入一次 iPhone 锁屏密码确认。

▲ iPhone 弹窗，必须点「信任」

连上没反应 / 列表里看不到设备？ 重插数据线、确认点了「信任」；Windows 检查是否装了 Apple Devices 驱动；Mac 可在「访达」左侧看到手机即说明连接正常。

3 打开 Sideloadly（macOS 可能要绕开拦截）

首次打开 Sideloadly，macOS 可能报「无法打开」，这是正常的（非 App Store 应用）。

“Sideloadly” 已被阻止
“Sideloadly” 已损坏，无法打开。
您的安全性偏好设置不允许打开这个来自未知开发者的应用。

▲ macOS Gatekeeper 拦截（示例）

  • 打开「系统设置 → 隐私与安全性」，滚到最下面，点 仍要打开（Open Anyway）
  • 或在终端执行一次：xattr -dr com.apple.quarantine /Applications/Sideloadly.app
  • Windows 首次打开同样允许杀软放行即可

▲ 设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID

  • 路径：设置 → 通用 → VPN 与设备管理（iOS 旧版可能在「描述文件与设备管理」）
  • 点你那个 Apple ID → 信任 → 再点一次「信任」
  • 这步不做，打开 App 会提示「无法验证 App」

回主屏幕，找到「简易笔记」图标，点开就能用了。首次打开可能再让输一次锁屏密码。

8 续签：7 天到期怎么办

免费签名 7 天后 App 会变灰打不开，重新签一次就行，数据不会丢。

  • iPhone 重新连电脑 → 打开 Sideloadly → 同样的 Apple ID + 同样的 IPA → 点 Start
  • 只要 Apple ID 和 IPA 不变，续签后笔记数据保留（存在 App 沙盒里）
  • 想省事：Sideloadly 勾选 Enable Auto-Refresh（需 iPhone 和电脑在同一 Wi-Fi，且电脑上的 Sideloadly 保持运行），它会自动在到期前续签

! 常见问题速查

「Apple ID 或密码错误」
开了 2FA 就在密码框填「应用专用密码」（appleid.apple.com 生成），不要用登录密码。
打开 App 提示「无法验证 App / 未受信任」
回到 第 6 步，去「设置 → 通用 → VPN 与设备管理」信任开发者。
App 图标变灰、点不开
免费签名 7 天到了，按 第 8 步 重新 Start 续签。
设备列表里看不到 iPhone
重插线、确认点了「信任此电脑」；Windows 装 Apple Devices 驱动；Mac 看访达里能否识别手机。
Start 后卡住 / 报错
拔插手机重来；确认 IPA 文件完整没下载截断；看 Sideloadly 菜单 View → Logs 查详细错误。
